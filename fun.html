Maple Programs:

Maple OEIS Search Function

A Maple program that queries the Online Encyclopedia of Integer Sequences (OEIS) to search for integer sequences directly from Maple. The function allows users to input a sequence of numbers and retrieve possible OEIS matches automatically.

Notes:

  • Takes six or more terms, as a sequence or a list: Search(1,1,2,3,5,8) and Search([1,1,2,3,5,8]) both give 45. More terms narrow the search.
  • The answer is the A-number without its leading zeros, so pad it back to six digits: 45 is A000045, the Fibonacci numbers. A sequence OEIS does not have comes back as -1.
  • Needs an internet connection. Within one Maple session a repeated search answers from memory, -1 included, so restart Maple before retrying a search that failed while you were offline.
  • Adapted from Daniel Skoog's Maple-OEIS, for Doron Zeilberger's Experimental Mathematics course.
  • Modified with help from Claude (AI).
  • Verified Working: 9/28/2026
