Maple Programs:

Maple OEIS Search Function

A Maple program that queries the Online Encyclopedia of Integer Sequences (OEIS) to search for integer sequences directly from Maple. The function allows users to input a sequence of numbers and retrieve possible OEIS matches automatically.

Usage:

  • Open the file in Maple and run all of it, then call Search with your sequence: Search(1,1,2,3,5,8) gives 45. Run the whole file, not just the Search procedure — the OEIS web address sits on its own line above it.
  • Enter the terms the way you would write them out, separated by commas. Search(1,1,2,3,5,8) works; Search([1,1,2,3,5,8]) does not, because the square brackets make it a list rather than a sequence.
  • Six terms is the minimum. More terms narrow the search.
  • The answer is the A-number with its leading zeros dropped, so pad it back to six digits: 45 is A000045, the Fibonacci numbers. Likewise Search(2,3,5,7,11,13) gives 40 for A000040, the primes.
  • You get -1 when OEIS has nothing matching the sequence.

Errors:

  • 6 or more integers required; received ... — either fewer than six terms, or something that is not a whole number, reached the function. The message lists what it received, which is usually enough to spot the problem. A sequence typed in square brackets lands here too.
  • curl returned no data ... Exit code: 6 — the search never reached OEIS. Check your internet connection and try again. curl is the small program Maple hands the request to; it ships with current versions of Windows and macOS, so this is almost always a connection problem rather than a missing program.

Notes:

  • The search runs over the internet, so you need to be online.
  • Repeating a search in the same Maple session answers instantly, because the answer is remembered. That applies to -1 as well, so if a search came back -1 while you were offline, restart Maple before trying it again.
  • Adapted from Daniel Skoog's Maple-OEIS, for Doron Zeilberger's Experimental Mathematics course.
